收集世界的灵感 · 只属于你

  1. 打开 github.com/settings/tokens
  2. 点 Generate new token → Fine-grained token
  3. Token name 随意，有效期自选
  4. Repository access 选 Only select repositories，勾选 diary-data
  5. Permissions → Repository permissions → Contents: Read and write
  6. Generate 后复制令牌，粘贴到上方

令牌只存在你自己浏览器里（localStorage），不会上传到任何服务器。所有数据写进你的私有仓库 diary-data。
